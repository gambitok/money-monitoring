# money-monitoring

Локальний облік доходів і витрат: щоденне введення операцій, категорії, зведена таблиця по місяцях, імпорт старих витрат з Excel. Валюта — гривня.

Стек: Node.js 24, Express 5, better-sqlite3, vanilla JS.

План робіт: [docs/plan.md](docs/plan.md)

## Запуск

Потрібен Node.js 24+.

```bash
npm install
npm start
```

Відкрий http://localhost:3001.

- `npm run dev` — те саме, але з автоперезапуском при зміні файлів (`node --watch`).
- `npm test` — тести (`node:test`, кожен прогін на тимчасовій БД).
- `launch.ps1` (Windows) — піднімає сервер у згорнутому вікні, якщо він ще не працює, і відкриває браузер.

## Налаштування

| Змінна | За замовчуванням | |
|---|---|---|
| `PORT` | `3001` | порт сервера |
| `DB_FILE` | `data/money.db` | файл SQLite |

Дані зберігаються в `data/money.db` (каталог у `.gitignore`). Для бекапу достатньо скопіювати цей файл при зупиненому сервері.
